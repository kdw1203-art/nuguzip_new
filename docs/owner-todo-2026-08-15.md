## 🔴 지금 바로 (심사·핵심 기능 블로커)

### 1. 토스 심사 회신 메일 발송
`docs/toss-reply-final.md` 를 그대로 복사해 회신. 발송 전 3가지만 채우면 완료:
- **테스트계정**: https://nuguzip.com/signup 에서 `test@nuguzip.com` 가입 →
  이메일 인증 → 회신에 ID/PW 기재 (소셜 로그인 불가, 흔한 비밀번호는 거절되니
  무작위 문자열)
- **빌링 신청 여부**에 맞춰 1) 문장만 조정 ("추가 신청합니다" ↔ "신청하였습니다")
- **결제경로 PPT 2종**(단건용·정기결제용)에 실제 화면 캡처(도메인+PC 시계 보이게)
  삽입 후 첨부
- 심사 지연 안내에 대한 **취소 의사가 없으면** 위 답변만 보내면 됩니다.

### 2. vault `cron_secret` 등록 ⚠️ 현재 미등록
Supabase 대시보드 → Project Settings → **Vault** → 새 시크릿 `cron_secret`
= (Vercel 의 `CRON_SECRET` 과 동일 값). 등록하면 **지금 잠들어 있는 3개 크론**이
살아납니다: 빌링 갱신·소셜 드레인·소셜 오토포스트. (절차 상세: docs/social-shorts-setup.md C절)
- 미등록이어도 사이트·결제·검색·에러 경보는 정상 동작합니다. 이건 "자동 발행·자동
  갱신"만 켜는 스위치입니다.

## 🟠 빌링(자동결제) 개방 시 (전자계약 승인 후)

3. **빌링 전자계약 신청**: 토스 홈페이지 > 이용 신청하기 > 직접 구축 > 빌링(정기결제)
4. 승인 후 **Vercel 환경변수 `NEXT_PUBLIC_TOSS_BILLING_ENABLED=1`** 추가 → 재배포
5. **개발자센터 웹훅 등록** (내 개발정보 > 웹훅, MID `nuguzibowg`):
   - URL `https://nuguzip.com/api/payments/toss/webhook`
   - 이벤트 `PAYMENT_STATUS_CHANGED` + `BILLING_DELETED`
- 이 3개가 끝나면 카드 등록·자동 갱신·해지가 실제로 열립니다(코드·검증은 완료됨).

## 🟡 성장 기능 자격증명 (없으면 조용히 무음)

6. **`RESEND_API_KEY`** (Vercel) — 이메일 발송(주간 다이제스트·알림). 없으면 이메일
   안 나감(에러는 안 남).
7. **VAPID 키** — 웹 푸시 알림. `npm run` 스크립트로 키 생성 후 Vercel 등록.
8. **Meta / Google OAuth** — 인스타 릴스·유튜브 쇼츠 자동 업로드(docs/social-shorts-setup.md A·B절).
9. (선택) **`NEXT_PUBLIC_TOSS_WIDGET_VARIANT_KEY`** — 계약 후 토스 상점관리자에서
   만든 결제 UI(프로모션 배지·A/B)를 코드 수정 없이 적용하고 싶을 때.
