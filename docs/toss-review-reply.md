## A. 그대로 복사해 회신할 답변 초안

### 1) 결제 수단
- 현재 사이트는 **월간·연간 이용권**을 판매합니다.
- **[소유자 결정 필요]** 두 가지 중 택1:
  - (a) **1회성 단건 결제만** 진행 → 현재 상태로 심사 가능. 자동 반복청구(빌링) 없음.
  - (b) **카드 등록 후 매월 자동결제(빌링/정기결제)** 도 운영 → 빌링 전자계약을 **추가 신청**해야 함
    (토스 홈페이지 > 이용 신청하기 > 직접 구축 > 빌링(정기결제)). 최초 1회 가입비만 부과, 중복분 환불.
  - 참고: 사이트에는 정기결제(빌링) UI가 구현되어 있으므로, 자동갱신을 실제로 켤 계획이면 (b) 가 맞습니다.
    자동갱신 없이 이용권 단건만 팔 계획이면 (a) 로 답하시면 됩니다.

### 업종 관련 추가 회신
- **"매물 등록" 기능**: 이용자가 매물 정보를 등록·열람하는 **정보 게시·노출 플랫폼**이며,
  누구집이 직접 **중개(브로커리지)·계약·자금 정산에 관여하지 않습니다.** (사이트 내 명시 고지)
- **"전문가 상담"에 법무(법무사·변호사) 포함 여부**: **포함하지 않습니다.**
  법률 서비스가 입점 불가임을 확인하여, 2026-08-12 사이트에서 **법무/계약 검토 상담 카테고리와
  법무사·변호사 전문가 유형을 전면 제거**했습니다. 현재 상담 업종은 공인중개사·세무사·감정평가사·
  대출상담사·기타 전문가뿐입니다.
- **수익 보장·확정 수익 문구**: **사이트 내 영구 미기재** 방침을 이미 적용했습니다.
  전 페이지 푸터 + 결제·구독·마켓 화면에 "수익 보장·확정 수익 등 수익을 약속하는 표현을 일절
  기재하지 않으며 앞으로도 영구적으로 기재하지 않습니다" 고지를 노출하고 있으며, AI 답변 생성
  단계에서도 해당 표현을 차단합니다.

### 3) 서비스 제공기간
- ① 최대 제공기간: **12개월** (연간 이용권 기준). 월간은 1개월.
  - 6주·12개월 초과 없음 → 입점 정책 충족.
  - 제공기간이 6개월(연간)인 경우 가상계좌 결제수단은 사용 불가 정책 → 카드/계좌이체/간편결제로 운영.
  - 사이트 결제·구독 화면에 "서비스 제공기간: 결제 즉시 적용, 선택 기간(월간 1개월 ~ 최대 12개월) 제공,
    7일 이내 청약철회 전액 환불" 을 명확히 표기해 두었습니다.

## C. 소유자가 직접 해야 할 것 (제가 대신 못 하는 것)

1. **사업장 주소에 층수·동호수 추가** — 토스는 "사업장 주소(층수 및 동호수까지)"를 사업자등록증과
   **완전히 동일하게** 요구합니다. 현재 푸터 주소는 `안양시 동안구 관양동 1588`로 층/호가 없습니다.
   - 조치: Vercel 환경변수 `NEXT_PUBLIC_COMPANY_ADDRESS`(또는 `COMPANY_ADDRESS`)를 사업자등록증
     상의 **전체 주소(도로명 + 건물 + 층/호)**로 설정 → 재배포하면 푸터에 그대로 반영됩니다.
   - ⚠️ 반드시 사업자등록증 표기와 글자 하나까지 동일해야 카드사 심사 반려를 피합니다.

2. **결제 수단 결정 (위 A-1)** — 빌링(정기결제) 계약 추가 신청 여부.

3. **심사관용 테스트계정** — 이메일/비밀번호 계정 1개 발급 후 회신에 ID/PW 포함 (소셜 계정 불가).

4. **결제경로 PPT 제작** — "메인 → 상품 선택 → 결제 → 결제창 확인" 흐름을 토스 예시 양식대로
   PPT로 만들어 첨부. (PDF 불가, PPT만)

5. **통신판매업 신고번호** — 현재 "신고 진행 중"으로 표기 중. 신고번호가 나오면 환경변수
   `NEXT_PUBLIC_COMPANY_MAIL_ORDER_NUMBER` 갱신. (없어도 국민카드만 제외되고 타 카드사 심사는 진행 가능)

6. **유선번호 확인** — 현재 푸터에 표기된 대표전화가 실제 수신 가능한 번호인지 확인.

7. **심사 기간 중 홈페이지 고정** — 카드사 심사(7~14일) 동안 사업자정보·전화번호·상품 카테고리·
   비회원 결제수단·판매상태(품절 등)를 **수정하지 마세요.** 수정 시 반려되어 처음부터 재심사됩니다.
