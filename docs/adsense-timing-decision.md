# [#86] 애드센스 신청 시점 판단 — 2026-08-23

## 결론
**지금 신청하지 않는다.** 신청 트리거를 아래 수치로 고정해 두고, 아침 리포트가
그 수치를 넘는 주에 신청한다.

## 근거 (실측)
- 현재 트래픽: 일 1~13 세션 (Vercel Analytics 실측 주간 45방문 수준)
- 애드센스 승인 심사는 "충분한 콘텐츠 + 실제 방문자"를 본다. 콘텐츠는 충분
  (지역 250p·단지 2.6만p·뉴스 700건·도구 10종)하나 방문자가 사실상 0이라
  지금 신청하면 "가치 낮은 콘텐츠(트래픽 부족)" 사유의 반려 확률이 높고,
  반려 이력은 재심사를 느리게 만든다.
- 준비 자체는 완료: docs/adsense-readiness.md (광고 슬롯·개인정보처리방침·
  ads.txt 준비 절차 포함).

## 신청 트리거 (둘 다 충족되는 첫 주)
1. 일 평균 100세션 이상이 14일 연속 (Vercel 대시보드 기준 — 봇 제외 실측)
2. 색인 등록 페이지 1,000개 이상 (Search Console — 소유확인(오너 패킷 ②) 선행 필요)

## 신청 당일 순서
readiness 문서의 체크리스트 → ads.txt 배포 → 신청 → 심사 중 광고 슬롯은
하우스 광고 유지(빈 슬롯 금지).

## 리스크 메모
- 심사 중 자동수집 뉴스가 "복제 콘텐츠"로 읽힐 수 있음 — 뉴스 요약 백필(진행 중,
  164건 재작성)이 끝난 뒤가 안전하다. 백필 완료 예상: 2026-08-30 전후.
