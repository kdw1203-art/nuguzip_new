# 스태프 공개 임장노트 시드 (ops)

가짜 “공작아파트” 샘플은 제품에서 제거됨. 피드 공백을 채울 때는 **실제 스태프 계정**으로만 시드한다.

## 절차

1. 스태프 Google/이메일 계정으로 로그인  
2. `/notes/new` 에서 실제 임장 경험 기준으로 노트 작성 (주소·사진·체크리스트)  
3. AI 요약 실행 후 공개(`is_public`) 설정  
4. `/notes`, `/town` 피드·홈에서 노출·CTA 확인 (공작 등 가짜 예시 카드는 제품에 없음)  
5. 주기: 주 1회 이상 신선도 유지 (만료·비공개 정리)  
6. 매물·전문가 cold start는 시드가 아니라 **범위 축소 카피**(베타·공급 적음)로 정직하게 안내

## 금지

- mock ID·허구 단지명·가공 KPI를 라이브처럼 표시  
- 개인 식별 가능 사진(얼굴·차량번호) 무단 공개  
- 서비스 롤 키로 DB에 샘플 행을 몰래 insert (감사용 감사 추적 불가)

## 검증

- 비로그인 `/notes` 에 공개 노트 ≥1 또는 정직한 empty+CTA  
- 노트 상세에 AI `source` 라벨(llm/rule)이 위장되지 않음
