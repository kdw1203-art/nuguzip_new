# 커뮤니티 배포 플레이북 — 카페·오픈챗 첫 4주

> [945 · 실사용50 #29] 실행 주체: **소유자 본인**. 이 문서는 절차·예시·측정만 제공한다.
> 원칙: **홍보 글이 아니라 진짜 후기 글**. 본인이 실제로 다녀온 임장, 실제로 쓴 노트만
> 소재로 쓴다. 없는 경험·없는 사용자·없는 성과를 지어내는 글은 쓰지 않는다(이건
> 브랜드 원칙이자, 카페에서 강퇴당하는 가장 빠른 길이기도 하다).

## 왜 이걸 하나

- 검색 색인은 느리다(사이트맵 2.6만 페이지 제출됨, 색인은 수 주 단위).
- 광고는 이르다(전환 루프 검증 전).
- 초기 부동산 서비스의 실사용자는 예외 없이 **부동산 카페·오픈챗**에서 나온다.
- 목표: 주 2회 × 4주 = 8개 글, 글당 방문 10~30명, 4주 누적 **가입 5명·노트 3편**.

## 지켜야 할 규칙 (모든 채널 공통)

1. **각 카페의 홍보 규정을 먼저 읽는다.** 링크 금지 카페에서는 링크를 빼고 글만 쓴다
   (닉네임·프로필로 찾아오게 두는 것까지가 허용선).
2. **후기가 본체, 도구는 곁가지.** 글의 8할은 임장 후기·데이터 해석이고,
   내집나우 링크는 "기록은 여기 정리했다" 한 줄로만 등장한다.
3. **본인 명의, 일관된 닉네임.** 여러 계정·가짜 반응(자문자답) 금지.
4. **숫자는 전부 출처와 함께.** 실거래는 "국토부 신고 기준", 지수는 "부동산원/KB".
5. 질문 댓글에는 **당일 답변** — 초기에는 글보다 댓글이 신뢰를 만든다.

## 채널 후보 (우선순위 순)

| 채널 | 성격 | 첫 4주 역할 |
|---|---|---|
| 네이버 대형 부동산 카페 (부동산스터디 등) | 임장 후기 문화가 이미 있음 | 주력 — 후기 글 |
| 지역 맘카페 (관심 지역 소재) | 실거주 수요, 링크 규정 엄격한 편 | 정보 답변 위주 |

| 클리앙·더쿠 등 종합 커뮤 부동산 게시판 | 데이터 글 반응 좋음 | 데이터 해석 글 |

## 글 유형 3종 (주 2회 로테이션)

- **A. 임장 후기형**: 실제 다녀온 단지 2~3곳 비교 후기 + 노트 링크.
- **B. 데이터 해석형**: "이번 주 우리 구 실거래 요약" — 지도/갭 랭킹 스크린샷 + 해석.
- **C. 질문 답변형**: 남의 질문(전세가율? 입주장?)에 성실 답변 + 관련 가이드 링크.

## UTM 규칙 (측정)

모든 링크는 아래 형식으로 붙인다. 성과는 **관리자 → 트래픽(/admin/traffic)의
UTM 캠페인 표**에서 세션 단위로 집계된다(30일 창).

```
https://nuguzip.com/notes/<id>?utm_source=cafe&utm_medium=community&utm_campaign=<채널>-w<주차>
예) ...?utm_source=cafe&utm_medium=community&utm_campaign=bdstudy-w1
```

- `utm_source`: cafe | openchat | clien …
- `utm_campaign`: 채널약어-주차 (글 단위 구분이 필요하면 `-a`,`-b` 접미)
