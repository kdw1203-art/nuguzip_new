## 응답 기준 (SLA)

- **1차 응답: 24시간 이내** (영업일 기준) — 해결이 아니라도 "받았고, 언제까지"
- 해결 목표: 일반 3영업일 · 환불 3영업일(sop-refunds 기준) · 버그는 심각도별
  (서비스 불능=당일, 기능 오류=48시간, 불편=다음 배포)
- 야간·주말: 자동 응답 없이도, 다음 영업일 오전 처리 원칙

## 처리 흐름

1. 접수 → 유형 분류: [버그] [환불] [계정] [크리에이터] [제휴] [기타]
2. 버그: 재현 확인 → AGENT 세션에 그대로 전달(스크린샷·계정·시각) → 수리 배포
   후 "고쳤습니다 + 무엇이 바뀌었나" 회신 — **수리 완료 회신까지가 처리다**
3. 계정: 본인 확인(가입 이메일 발신 여부) 전에는 어떤 정보도 변경·제공하지 않음
4. 기록: 처리한 문의는 유형·소요시간을 주간 브리핑 지표에 편입(월 리뷰)

## 답변 원칙

- 사실 우선 — 모르면 "확인 후 언제까지 답변" (추측 답변 금지)
- 화면 고지와 다른 약속 금지 (환불·정산·기능 일정)
- 템플릿보다 짧은 진짜 문장 — 초기엔 창업자의 목소리가 곧 브랜드다

## 향후 자동화 (로드맵)

- RESEND 개통 시: 접수 자동 회신(접수 확인+예상 기한)
- 문의 유형 통계를 주간 브리핑 계기판에 추가
