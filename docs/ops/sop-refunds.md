> **누가·언제·어떻게** 집행하는지의 내부 절차만 다룬다. 정책과 절차가 어긋나면
> 정책(공표문)이 이긴다 — 절차를 고쳐라.

## 원칙 3

1. **환불 판단은 24시간 내 1차 응답** — 승인이 아니라 "접수했고 언제까지 답한다"까지.
2. **디지털 콘텐츠(리포트)의 특성상 열람 후 단순변심 환불 불가**가 기본이되,
   내용 부실·허위(제목과 실내용 불일치)는 플랫폼 귀책으로 취급해 환불한다.
3. **분쟁에서 기록이 전부다** — 처리 근거(어떤 조항, 어떤 사실)를 남기지 않은
   환불/거절은 없던 일과 같다.

## 절차 — 포인트 충전 환불

1. 접수: nuguzip@naver.com (제목에 [환불]) 또는 토스 결제 이의제기.
2. 확인: 어드민에서 결제·포인트 사용 내역 조회 (미사용분/사용분 구분).
3. 판단: **미사용 포인트 = 결제 취소** (토스 개발자센터에서 해당 결제 취소 —
   부분취소는 미사용분만). 사용분은 약관 환불 조항 기준.
4. 처리 기한: 접수 → 판단 3영업일 이내, 취소 실행 즉시.
5. 기록: 처리 내역을 어드민 메모/원장에 남긴다 (사유·조항·금액·일시).

## 절차 — 유료 리포트 환불 (구매자 ↔ 크리에이터)

1. 구매자 신고 접수 (제목·사유·리포트 id).
2. 열람 여부 확인 (전달물=노트 열람권 — 열람 로그 기준).
3. 분기:
   - 미열람 + 24시간 내: 환불 (포인트 원복, 크리에이터 정산 대기분에서 차감)
   - 열람 후 내용 부실·허위 주장: 리포트 실내용 대조 → 타당하면 환불 +
     해당 리포트 판매 중지, 크리에이터에게 사유 통지
   - 단순변심(열람 후): 공표 정책대로 불가 — 근거 조항을 들어 회신
4. 동일 크리에이터 환불 2회 누적 시: 신규 판매 보류 + 소명 요청.

## 에스컬레이션

- 금액 10만 원 초과·법적 대응 언급·언론/커뮤니티 공론화 조짐 → 즉시 OWNER 판단.
- 카드사 지급정지(chargeback) 통지 → 토스 절차 우선, 자체 판단 중지.
