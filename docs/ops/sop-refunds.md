> **누가·언제·어떻게** 집행하는지의 내부 절차만 다룬다. 정책과 절차가 어긋나면
> 정책(공표문)이 이긴다 — 절차를 고쳐라.
>
> v2 변경: 결제 상품 현실에 맞게 재작성. 판매 중인 유료는 **① 구독(주간권
> 단건 / 월간·연간 정기결제) ② 유료 리포트** 둘뿐이다. 포인트는 무상 리워드
> (제8조의2)라 현금 환불 대상이 아니다 — 유상 충전 상품은 존재하지 않는다.

## 원칙 3

1. **환불 판단은 24시간 내 1차 응답** — 승인이 아니라 "접수했고 언제까지 답한다"까지.
2. **디지털 콘텐츠(리포트)의 특성상 열람 후 단순변심 환불 불가**가 기본이되,
   내용 부실·허위(제목과 실내용 불일치)는 플랫폼 귀책으로 취급해 환불한다.
3. **분쟁에서 기록이 전부다** — 처리 근거(어떤 조항, 어떤 사실)를 남기지 않은
   환불/거절은 없던 일과 같다.

## 절차 A — 구독 해지 (다음 결제부터 중단)

1. 접수 경로: 사용자 스스로 /subscription 의 해지 신청 버튼(CancelRequestButton)
   또는 고객센터(/support) 접수.
2. 처리: 관리자 → 결제(/admin/payments)에서 해당 사용자의 자동결제 해지 처리
   (빌링키 해지 = /api/payments/toss/billing/cancel 경유 화면 버튼). 해지 시
   **다음 결제 예정일부터 청구되지 않는다** — 이미 결제된 기간은 만료일까지 이용.
3. 회신: "해지 완료 · 이용 가능 기한 YYYY-MM-DD" 한 줄을 접수 채널로.

## 절차 B — 청약철회 (결제 후 7일 이내, 이용 개시 전 전액)

1. 확인: 결제일로부터 7일 이내인지, 유료 기능 실사용 이력이 있는지
   (관리자 결제 기록 + AI 사용량으로 확인).
2. 처리: 관리자 → 결제 → 해당 건 **전액 취소** 버튼
   (/api/admin/payments/cancel — 토스 취소 API·멱등, refunded 기록까지 자동).
   플랜 강등은 취소 처리에 연동된다 — 별도 수작업 없음.
3. 기한: 접수 → 3영업일 이내 취소 실행 (전자상거래법 환급 기한 준수).

## 절차 C — 중도 해지 일할 환불 (약관 제8조)

1. 계산: 결제액 × 잔여일 ÷ 결제 주기 일수 (원 단위 내림). 계산 근거를 회신에 적는다.
2. 처리: 관리자 → 결제 → **부분 취소**에 일할 금액 입력
   (/api/admin/payments/cancel 이 부분취소 금액·사유("중도 해지 일할 환불 …
   약관 제8조")를 기록한다).
3. 자동결제 구독이면 절차 A(빌링키 해지)를 **먼저** 실행 — 환불 후 다음 달
   재청구되는 사고를 막는 순서다.

## 절차 — 유료 리포트 환불 (구매자 ↔ 크리에이터)

1. 구매자 신고 접수 (제목·사유·리포트 id).
2. 열람 여부 확인 (전달물=노트 열람권 — 열람 로그 기준).
3. 분기:
   - 미열람 + 24시간 내: 환불 (포인트 원복, 크리에이터 정산 대기분에서 차감)
   - 열람 후 내용 부실·허위 주장: 리포트 실내용 대조 → 타당하면 환불 +
     해당 리포트 판매 중지, 크리에이터에게 사유 통지
   - 단순변심(열람 후): 공표 정책대로 불가 — 근거 조항을 들어 회신
4. 동일 크리에이터 환불 2회 누적 시: 신규 판매 보류 + 소명 요청.
