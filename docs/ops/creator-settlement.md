# SOP — 크리에이터 정산·세무 실무 (v1 초안, 2026-08-17)

> 현재 상태의 사실: 판매 수익은 포인트(P)로 적립되고, **현금 출금 인프라는
> 미구현**(lib/creator/sales.ts payoutReady=false — 화면에도 그렇게 고지).
> 이 문서는 출금을 열기 **전에** 갖춰야 할 실무를 미리 적어 두는 초안이다.
> ⚠️ 세무 항목은 세무사 확인 후 확정 — 이 문서는 세무 자문이 아니다.

## 정산 구조 (공표 정책과 일치해야 함 — /legal/fees 원천)

- 판매가(P) − 플랫폼 수수료(등급별 요율) = 크리에이터 적립분
- 최소 정산 신청액: 30,000원 상당 (SETTLEMENT.minPayoutKrw)
- 전환: 포인트 → 현금, **관리자 승인 후** 지급

## 출금 개시 전 체크리스트 (전부 충족 전에는 열지 않는다)

- [ ] 지급 수단 확정 (계좌이체 실무 — 지급 주기·마감일 규정)
- [ ] 실명·계좌 확인 절차 (오지급은 회수가 거의 불가능하다)
- [ ] ⚠️ 원천징수 처리 확정 — 개인 크리에이터 사업소득 3.3% 공제·신고·지급명세서
      제출 실무를 세무사와 확정 (누가 언제 신고하는가)
- [ ] 지급 대장 양식 (일시·대상·총액·공제·실지급·근거)
- [ ] 정산 화면의 고지 문구를 실무와 일치시키기 (지급일·공제 표시)

## 월간 운영 루틴 (출금 개시 후)

1. 매월 1일: 전월 판매 확정분 집계 (환불 반영 후)
2. 5일: 정산 신청 마감 → 검증(실명·계좌·금액)
3. 10일: 지급 실행 + 대장 기록 + 크리에이터 통지
4. 세무 일정: ⚠️ 원천세 신고·납부 기한 준수 (세무사 일정표 따름)

## 회계 기초 (⚠️ 세무사 확인 필요 항목)

- 포인트 충전 시점 vs 사용 시점의 매출 인식
- 플랫폼 수수료 매출과 크리에이터 지급분의 구분 기장
- 부가세 처리 (수수료분) · 현금영수증/세금계산서 발행 기준

## 지금 당장 유효한 것 (출금 전에도)

- 판매·적립 내역은 이미 실데이터로 기록·표시된다 — 이 기록이 정산의 원천
- 문의 시 답변 기준: "현금 정산은 준비 중, 개시 시 크리에이터 센터에 먼저
  공지" (화면 고지와 동일 문구 — 다른 약속 금지)
