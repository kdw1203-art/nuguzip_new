# 누구집 SEO·GEO 2차 25선 — 심화 제안

## 실행 순서 제안

**즉시 (코드, 반나절권):** N1 IndexNow → N3 RSS → N16 llms-full.txt → N18 언론 인용 섹션
**소유자 10분 작업 2건:** N2 Bing 등록 · N22 data.go.kr 활용사례 등록
**데이터가 쌓인 뒤 (2~4주 후):** N24 쿼리 갭 루틴 · N25 색인률 대시보드 · N11 시장 온도 아카이브
**전국 데이터 완성 후 (수집 순회 1~2회전 뒤):** N9 지역 가이드 · N10 단지 비교 랜딩

**하지 말 것 (1차와 동일한 경계):** 거래가 얇은 조합의 비교 페이지 양산(N10 기준 미달 시 생성 금지),
AI 에게 잘 보이기 위한 통계 가공 — 사실 우선 원칙은 2차에서도 동일하게 적용된다.
