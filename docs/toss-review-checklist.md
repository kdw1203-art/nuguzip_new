## 1. 홈페이지 필수 요건 (심사관이 사이트에서 직접 확인)

- ✅ **하단 푸터 사업자정보** — 전 페이지 공통 푸터(`app/components/Footer.tsx`,
  값은 `lib/brand/business-info.ts` 단일 출처):
  상호명(우리동네이야기) · 대표자명 · 사업자등록번호 · 사업장주소 ·
  유선번호(050 안심번호 — 허용 번호체계) · 통신판매업 신고번호.
  ※ **사업자등록증과 완전히 동일해야** 카드사 반려가 없다 — 값 변경은
  `business-info.ts` 한 곳만 고친다.
  - 🔶 통신판매업 신고번호: 현재 "신고 진행 중" 표기. 번호 발급 즉시
    `NEXT_PUBLIC_MAIL_ORDER_SALES_NUMBER` env 로 주입(코드 수정 불필요).
    FAQ: 신고번호 없이도 PG 계약·카드사 심사 진행 가능(국민카드만 제외),
    간이과세자는 없어도 됨.
- ✅ **환불규정(무형재화)** — 이용약관 제8조(`/legal/terms#refund`): 7일 내
  청약철회 전액 환불 + 중도 해지 잔여기간 일할 환불. `/subscription` 과
  결제 화면에서 직링크·요약 표기.
- ✅ **서비스 제공기간(무형재화 필수)** — 결제 즉시 적용 · 선택 기간(월간
  1개월~최대 12개월) 표기(`ComplianceNotice variant="payment"` —
  `/subscription`, `/subscription/checkout`). 가이드 경고: 제공기간이 1년을
  초과하면 결제 서비스 이용 불가 → 우리 최장 상품은 12개월이라 충족.
- ✅ **상품·가격 표시** — 구독 플랜 카드에 월간/연간 실제 결제 가격 명시.
  FAQ 금지사항: 테스트 상품·0원 상품·품절 상품·가격 없이 문의만 있는 형태.
  (무료 플랜 "0원"은 판매 상품이 아니라 기본 플랜 표기 — 결제 대상은 유료

- ✅ **로그인·회원가입 경로** — `/login`, `/signup` 정상 동작(2026-08-10
  가입 오류 수정 완료). 심사관용 테스트 계정은 결제경로 파일에 기재(아래).
- ✅ **수익 보장 문구 영구 미기재 방침** — 소유자 방침. 전 페이지 푸터 +

## 2. 결제경로 파일 (🔶 소유자 제작 — PPT 필수, PDF 불가)

구성 순서 (세 가이드 공통):
1. **표지 — 가맹점 정보**: 상호명 / 사업자번호 / URL(https://nuguzip.com) /
   테스트 ID·PW (심사관 확인용 계정 — 실계정 하나 만들어 기재)
2. **하단정보 캡처**: 푸터의 사업자정보 6항목이 보이게
3. **환불규정 캡처**: `/legal/terms#refund` 조항 화면 (빌링 가이드 예시처럼
   정기결제 일할 환불 문구 포함된 부분)
4. **로그인/회원가입 캡처**: `/login` 화면
5. **상품선택/구매과정 캡처**: `/subscription` 플랜 선택 → 결제하기 →
   `/subscription/checkout` 까지 흐름 전부
6. **카드 결제경로 캡처**: 결제위젯 창(신용·체크카드 선택, 카드사 목록) —
   테스트용 결제창으로도 심사 가능. **비씨카드는 카드사 인증 화면까지** 필수.

제작 유의사항:
- 반드시 **PPT 형식**(카드사별 양식 수정 대비), 계약담당자에게 PPT 로 전달
- 모든 캡처는 **북마크바 없이 도메인(주소창)이 보이게**
- **PC 시계(시간)가 함께 캡처**되어야 함 (조작 여부 판단용)
- 상품 명칭·이미지·설명·금액·결제창 흐름이 모두 확인되어야 함
- 정기결제(빌링) 상품은 빌링 가이드 양식으로 별도 구성

## 3. 카드사 심사 기간(약 10–14일) 중 사이트 수정 금지 항목 (🔶 운영 주의)

심사 중 아래를 수정하면 카드사 반려 → 처음부터 재심사 → 정산 지연:
- 하단 **사업자정보·전화번호** (푸터 — 이 기간엔 `business-info.ts` 배포 금지)
- **상품 카테고리** / **판매 상태**(품절 등) / **비회원 결제수단**
- 결제창(신용카드 결제창)이 열리지 않는 상태가 되면 반려
- 심사관이 접근할 수 있도록 **테스트 계정 유지** 필수

## 4. 기타 (FAQ)

- 서류: 개인사업자는 사업자등록증(제출용)만. 3개월 이내 요건 주의.
- 심사 현황 확인: 상점관리자(app.tosspayments.com) → 이용정보 → 결제·부가서비스.
- 면세/복합과세: 기본 복합과세 — 우리는 과세 단일이므로 해당 없음(면세 파라미터
  미전달 시 전체 과세 승인 = 정상).
- 결제위젯(신버전) 연동 — 이미 결제위젯 경로(`/subscription/checkout` →
  CheckoutClient → /api/payments/toss/create → 위젯 → /payment/success) 사용 중.
- 브랜드페이 가이드는 브랜드페이 **단독심사** 전용 — 현재 결제위젯 일반+빌링
  구성에는 해당 없음. 브랜드페이 도입 시 그 가이드로 별도 결제경로 제작.
