> 2026-08-17 수립. 목표: **12개월 내 회원 1만 명**.
> 운영 체계(docs/ops/operating-system.md)와 짝을 이루는 "무엇을 할 것인가" 정본.

## 0. 전제 — 무엇으로 싸우는가

- **자원**: 누구집 (임장노트 + 실거래 지도 + 분석 도구 + 타운 + 리포트 마켓),
  1인 소유자 + AI 상시 운영 체계(하루 10+ 배포 가능, 고정 운영비 ≈ 0), 자본 최소.
- **상대**: 호갱노노(시세 조회 지배·직방 계열), 네이버부동산(매물 유통 독점),
  당근부동산(하이퍼로컬 직거래·신뢰), 숨고(범용 전문가 매칭 물량).
- 넷 다 자본·트래픽으로는 못 이긴다. **그들이 구조적으로 안 하는 것**에서만 싸운다.

## 1. 싸우지 않을 곳 (선언적으로 버린다)

| 버리는 것 | 이유 |
|---|---|
| 시세 조회 정면전 | 호갱노노가 데이터·UX·습관 전부 선점. 후발 조회앱은 존재 이유가 없다 |
| 매물 중개/유통 | 네이버 독점 + 규제·영업 비용. 우리는 광고 매체 포지션까지만 |
| 범용 커뮤니티·뉴스 | 커모디티. 유입은 되지만 정착·차별화가 안 된다 |
| 전국 커버리지 동시 확장 | 자본 게임. 깊이 없는 넓이는 어느 지역에서도 1등이 아니다 |
| 유료 광고 (현 단계) | LTV 미검증 상태의 광고비는 소각. 복리 회로 검증 후에만 |
| 범용 전문가 매칭 확장 | 숨고 물량전. 부동산 의사결정 맥락 안의 연결까지만 |

## 2. 불공정 우위 5 — 따라 하기 어려운 이유까지

**U1. 카테고리 창조 — "임장 관리"라는 새 칸.**
호갱노노는 *보는* 앱, 누구집은 *가는 사람의* 앱. 임장 준비→현장 기록→AI 정리→
비교→결정의 워크플로 전체를 소유한다. 대기업이 안 만드는 이유: 조회 트래픽
대비 너무 니치하고, 리스팅 DNA 로는 워크플로 제품이 안 나온다. 우리가 이기는
이유: **기록이 쌓일수록 이탈 비용이 커진다** (내 노트는 옮길 수 없다).

**U2. AI 속도 구조.**
기획→구현→검증→배포가 한 세션 안에서 돈다. 경쟁사의 스프린트 1개 분량을
하루에 처리하는 구조적 속도차 — 사용자 제보가 당일 배포로 돌아오는 경험
자체가 초기 커뮤니티에서 가장 강한 입소문 소재다. 이건 채용으로 복제가 안 된다.

**U3. 데이터 플라이휠 — 임장노트는 크롤링이 안 된다.**
시세는 공공데이터(누구나 있음), 현장 관찰(소음·결로·주차 실태·동별 차이·관리
상태)은 가 본 사람만 가진 데이터다. 공개 노트 → 단지 페이지 강화 → 검색 유입
→ 새 방문자 → 새 노트. 회전이 시작되면 후발 주자는 데이터 격차를 돈으로 못 산다.

**U4. 크리에이터 스톡 마켓 — 임장 콘텐츠 수익화 공백.**
임장 유튜버·블로거의 수익은 전부 플로우(조회수)형이고, 지역 분석 리포트를
파는 스톡 마켓은 비어 있다. 판매 루프(작성→승격→자료실 판매)는 이미 구현됨.
크리에이터 1명 입점 = 그의 관객이 유통 채널로 들어온다. 플랫폼 4사 모두
"데이터/리스팅 회사"라 크리에이터 커머스를 만들 조직이 아니다.

**U5. 수요 주도 확장 — 감이 아니라 줄 선 수요로 지역을 연다.**
커버리지 수요 수집(#413 가동 중)이 "어느 지역을 다음에 열지"를 데이터로
정렬해 준다. 경쟁사는 전국을 얕게, 우리는 수요 순서대로 깊게. 안양·과천·의왕
수도권 남부에서 "이 동네는 누구집이 제일 잘 안다"를 만든 뒤 그 모델을 복제한다.

## 3. 상품구조 — 무료로 모으고, 자산으로 잠그고, 거래로 번다

| 층 | 무엇 | 역할 |
|---|---|---|
| 무료 | 임장노트·지도·기본 분석 | 획득 + U3 플라이휠 연료 |
| 자산 | 내 기록·비교·레벨 | 잠금(이탈 비용). 팔지 않는다 |
| 거래 | 리포트 마켓(수수료)·구독 분석·전문가 연결 | 수익. 광고는 팔지 않는다 |

## 4. 콘텐츠 전략 — 사람이 안 쓰는 콘텐츠 공장

1. **소셜 자동 발행** (가동 시작) — 데이터→카드뉴스, 사람 0명.
2. **프로그래매틱 임장 랜딩** — 단지×임장 체크포인트 페이지. 단, 소프트404
   기준(실데이터 밀도) 충족 설계 후 — 얇은 대량 페이지는 SEO 자살이다.
3. **크리에이터 리포트** — 프리미엄 층은 우리가 안 쓰고 크리에이터가 쓴다.
4. **주간 지역 브리핑** — RESEND 개통 시 뉴스레터화(브리핑 자동화는 이미 있음).

## 5. 유통 전략 — 광고비 0원의 4개 회로

| 회로 | 메커니즘 | 상태 |
|---|---|---|
| SEO 복리 | 단지·실거래·노트 페이지 + 임장 키워드군 소유 | 가동, 확장 여지 큼 |
| 크리에이터 지참 관객 | 입점 크리에이터의 기존 팬 유입 | **/creators 오늘 개설** |
| 공유 노트 바이럴 | 임장 다녀온 노트 카톡 공유 = 광고 | 다음 스프린트(OG 강화) |
| 임장 크루 | 오프라인 소모임의 표준 도구화(타운 모임 기능) | 시드 필요(소유자) |

## 6. 브랜드 포지션

- **한 문장**: 시세는 누구나 봅니다. 현장은 가 본 사람만 압니다.
- **카테고리**: 임장 관리 플랫폼 (비어 있는 칸의 첫 이름).
- **대립 구도**: 보는 앱(호갱노노) vs **가는 사람의 앱(누구집)**.
- **어조**: 사실 우선(실패는 실패로 표기·수치 창작 금지)이 곧 브랜드 신뢰.

  크리에이터 파트너 / 자본=인프라 실비만, 광고비 0.
