# [#95] 법원경매 데이터 소스 재조사 — 2026-08-23

## 배경
1차 로드맵에서 법원경매 탭을 제거했다(수집 소스 부재로 스텁 1건뿐). 이 문서는
재도전 경로별 실현 가능성·비용을 정리한 판정 문서다.

## 조사 결과 (2026-08-23 웹 실측)

### 1) 대법원 사법정보공유포털 (openapi.scourt.go.kr) — 공식 무료 경로 후보
- 법원이 직접 운영하는 오픈API 포털이 존재하며 "연계 API"를 제공한다고 안내.
- 다만 포털 메인에서 API 목록이 확인되지 않아 **경매 데이터 포함 여부는 미확정**.
  회원가입 후 목록 확인 또는 고객센터(02-3480-1715) 문의가 다음 단계.
- 판단: **1순위 확인 대상** (무료·공식). 오너 액션: 포털 가입 후 경매 API 유무 확인.

### 2) 하이픈(hyphen.im) "부동산 법원경매 정보" — 상용 API (실측 확인됨)
- 11개 API: 사건번호·관할법원·감정가·기일내역·낙찰결과·권리분석(말소기준권리,
  예상배당표)까지 — 우리가 원하는 것 전부.
- 요금: **TR슬림 월 10만원 + 건당 종량** / TR시그니처 월 30만원~. 테스트베드 제공.
- 판단: 데이터 품질·범위는 충분하나 **현 매출 0 단계에서 고정비 월 10만원은 보류**.
  결제 오픈 후 유료 전환이 생기면 재검토(경매 기능의 구독 견인력을 근거로).

### 3) 직접 크롤링 (대법원 법원경매정보 사이트)
- 오픈소스 선례 존재(guriguri/cauca — crawler + REST). 기술적으로 가능.
- 법적 리스크: 공공 사이트지만 약관·robots 확인 필요, 대량 수집 시 차단 리스크,
  그리고 "권리분석" 같은 가공 데이터가 아닌 원시 기일/물건 정보만 얻는다.
- 판단: **비권장** — 유지보수 비용(사이트 개편마다 파손)이 상용 API 비용을 금방 넘는다.

## 결론 (권고 순서)
1. **오너**: 사법정보공유포털 가입 → 경매 API 존재 확인 (무료라면 즉시 연동 개발)
2. 존재하지 않으면: 결제 오픈 + 유료 구독 10건 도달 시 하이픈 TR슬림 계약 검토
3. 크롤링은 두 경로가 다 막혔을 때만 별도 리스크 검토 후
